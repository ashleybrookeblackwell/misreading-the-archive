# misreading-the-archive
This research entails the development of a reproducible pipeline to evaluate how OCR errors in digitized historical records propagate into named-entity extraction and historical relationship reconstruction. It will begin with U.S. National Archives records concerning postwar cultural heritage in Germany (National Archives Catalog and API, 2002).

# Defined around four measurements: 
- # Character Error Rate (CER): How many characters OCR gets wrong.
- # Word Error Rate (WER): How many words are corrupted.
- # Entity Recall: which people, places, institutions, dates, artworks, accession numbers, etc. survive machine reading.
- # Historical relationship preservation: Whether relationships (such as person → artwork → institution → location) survive the OCR/NLP pipeline.

# References
National Archives Catalog and API. (2002, September 16). Data.Gov; National Archives and Records Administration. http://catalog.data.gov/dataset/national-archives-catalog-and-api
